TEXTPILOT

TextPilot

Windows 10/11 Rust 2021 OpenAI-compatible API RAM ~2 MB Portable (≈1.3 MiB)

Select text, make one gesture, and optimize prompts or translate intelligently.

Hold Ctrl and quickly press F8 twice to optimize, or F9 twice to translate. Results go straight to the clipboard.
Features
  • ⚡ Minimal gestures, no main window
    Lives in the system tray and compresses “select → optimize → paste” into one global gesture. No chat window required.
  • 🎯 Smart selection capture
    Uses Windows UI Automation first to read text directly and show status near the selection. If that fails, it temporarily copies the selection and restores your clipboard afterward.
  • ⚙️ Configurable actions and tiered gestures (v0.5.0)
    Add, edit, or disable actions; set each action’s hotkey, dedicated model, and Standard / Deep prompts. Double and Triple gestures on the same key can route independently.
  • 🌏 Smart bidirectional translation (v0.4.0)
    Use a dedicated Ctrl + double-press F9 gesture. Translation direction is chosen automatically from your native and target languages, and every API profile can select separate models for optimization and translation.
  • 🪶 Extremely lightweight
    Written in native Rust without a bulky GUI runtime; uses about ~2 MB of memory while resident when Settings is closed.
  • 🎨 Apple / Win11-style Settings (v0.3.0)
    Settings uses the system WebView2 Runtime, with system light/dark colors, multiple profiles, custom dropdowns, and pill toggles. Its temporary Settings directory is cleaned up on close when possible.
  • 🔒 Stateless and privacy-conscious
    Each request sends only the current selection and configured rules; no conversation history is kept. Compatibility mode uses the clipboard only temporarily and restores it afterward.
  • 🌐 Compatible with common APIs
    Works with any OpenAI-compatible /chat/completions endpoint. Each service profile can store multiple models and choose separate optimization and translation models.

Quick Config (config.json)
Configuration is stored in config.json beside the EXE. Right-click the tray icon and choose “Settings” to manage multiple profiles in the modern interface.
{
  "active_profile": "默认配置",
  "api_profiles": [
    {
      "name": "默认配置",
      "api_key": "YOUR_API_KEY",
      "base_url": "https://api.openai.com/v1",
      "models": ["gpt-4o-mini", "gpt-5-mini"],
      "model": "gpt-4o-mini",
      "translation_model": "gpt-4o-mini",
      "temperature": 0.3,
      "max_tokens": 512
    }
  ],
  "hotkey": "Ctrl+DoubleF8",
  "translation_hotkey": "Ctrl+DoubleF9",
  "native_language": "中文",
  "target_language": "英语",
  "system_prompt": "你是一个提示词优化助手……只返回优化后的提示词。",
  "translation_prompt": "你是一个高精度的专业双向文本翻译引擎……",
  "actions": [
    {
      "id": "optimize",
      "name": "提示词优化",
      "hotkey": "Ctrl+DoubleF8",
      "profile": "默认配置",
      "model": "gpt-4o-mini",
      "system_prompt": "你是一个提示词优化助手……",
      "triple_prompt": "以深度模式优化提示词……",
      "enabled": true
    },
    {
      "id": "translate",
      "name": "智能文本翻译",
      "hotkey": "Ctrl+DoubleF9",
      "profile": "默认配置",
      "model": "gpt-5-mini",
      "system_prompt": "你是一个高精度的专业双向文本翻译引擎……",
      "triple_prompt": "输出原文与译文对照……",
      "enabled": true
    }
  ],
  "result_mode": "clipboard",
  "play_sound": true,
  "auto_start": false
}
models stores the available models for each profile. Every action binds a profile through profile and a model from that profile through model. Bindings are validated before saving and requests never silently use another action's profile or model. Legacy profile-level model fields remain for compatibility. In this version, result_mode is fixed to clipboard.
