PROMPT OPTIMIZER

PromptOptimizer

Windows 10/11 Rust 2021 OpenAI-compatible API RAM ~2 MB Portable (≈1.3 MiB)

选中文字，一次手势，优化提示词或智能翻译。

按住 Ctrl 快速按两次 F8 优化，或按两次 F9 翻译，结果自动进入剪贴板
Features / 核心特性
  • ⚡ 极简快捷，无需窗口
    常驻系统托盘，把“选区 → 优化 → 粘贴”压缩成一次全局快捷手势。不打开聊天主窗口。
  • 🎯 智能选区提取
    优先通过 Windows UI Automation 直接读取并在选区附近显示状态；失败时自动临时复制选区，读取后恢复原剪贴板。
  • ⚙️ 可配置动作与分级手势 (v0.5.0)
    新增、编辑或禁用动作，为每个动作配置热键、专属模型及 Standard / Deep 提示词；支持同键 Double 与 Triple 分级路由。
  • 🌏 智能双向翻译 (v0.4.0)
    使用独立的 Ctrl + 双击 F9 手势，根据母语与目标语言自动决定翻译方向；每套 API 配置可为优化和翻译分别选择模型。
  • 🪶 极致轻量常驻
    基于原生 Rust 编写，不打包庞大 GUI 运行时；未打开设置窗口时，后台常驻内存约 ~2 MB。
  • 🎨 Apple / Win11 风格设置界面 (v0.3.0)
    基于系统 WebView2 Runtime 渲染设置中心，支持系统深浅配色、多配置管理、自绘 Dropdown 和胶囊 Toggle；关闭窗口后尽力清理本次设置页临时目录。
  • 🔒 无状态与隐私安全
    每次只发送本次选区文本与配置规则，不维护会话历史；兼容模式只临时使用剪贴板并随后恢复。
  • 🌐 兼容通用 API
    支持任意 OpenAI 兼容的 /chat/completions 接口；每套服务配置可保存多个模型，并分别选择优化模型与翻译模型。

Quick Config / 配置参考 (config.json)
配置存储于 EXE 同目录的 config.json，右键托盘选择“设置”即可在现代化界面中快捷管理多套配置： 
{
  "active_profile": "默认配置",
  "api_profiles": [
    {
      "name": "默认配置",
      "api_key": "YOUR_API_KEY",
      "base_url": "https://api.openai.com/v1",
      "models": ["gpt-4o-mini", "gpt-5-mini"],
      "model": "gpt-4o-mini",
      "translation_model": "gpt-4o-mini",
      "temperature": 0.3,
      "max_tokens": 512
    }
  ],
  "hotkey": "Ctrl+DoubleF8",
  "translation_hotkey": "Ctrl+DoubleF9",
  "native_language": "中文",
  "target_language": "英语",
  "system_prompt": "你是一个提示词优化助手……只返回优化后的提示词。",
  "translation_prompt": "你是一个高精度的专业双向文本翻译引擎……",
  "actions": [
    {
      "id": "optimize",
      "name": "提示词优化",
      "hotkey": "Ctrl+DoubleF8",
      "model": "",
      "system_prompt": "你是一个提示词优化助手……",
      "triple_prompt": "以深度模式优化提示词……",
      "enabled": true
    },
    {
      "id": "translate",
      "name": "智能文本翻译",
      "hotkey": "Ctrl+DoubleF9",
      "model": "",
      "system_prompt": "你是一个高精度的专业双向文本翻译引擎……",
      "triple_prompt": "输出原文与译文对照……",
      "enabled": true
    }
  ],
  "result_mode": "clipboard",
  "play_sound": true,
  "auto_start": false
}
models 保存该配置的可用模型列表， model 与 translation_model 分别表示普通动作和翻译动作的回退模型； actions 保存动作、热键、专属模型和 Standard / Deep 提示词。动作专属模型在当前 API 配置不可用时会安全回退；内置动作与旧顶层字段由程序兼容迁移和同步。当前版本的 result_mode 固定为 clipboard。
